## 개요

여러 홈페이지에 흩어진 학교 일정을 한 캘린더로 모아 보여주는 웹 서비스 MiCAL(Merge in CAL)입니다. 1차는 기획 문서, 2차는 Frontend + Backend 구현 과제입니다. 저는 크롤링 결과를 받아 DB에 저장하고 화면에 API로 넘기는 서버 전체(DB 설계, Django API, 로그인·친구·AI 비서 API, 런어스 연동, 배포·운영)를 맡았고, 팀원들이 PM·크롤링·화면 디자인과 프론트를 맡았습니다.

```plain text
학교·학과 홈페이지 크롤링 (cron) ─┐
런어스 iCal URL 주기 수집 ─────────┼→ PostgreSQL → Django API → 캘린더 화면 (월·주)
개인 일정 입력 ────────────────────┘                  │
                                    Gemini (MiCA) ────┘   친구 · 공지 · 프로필
```
