## 개요

예약 시스템은 네이버 그대로 두고, 예약 뒤에 붙는 독립형 구조입니다. AI는 모발을 판정하지 않고 고객 답변을 상담 카드로 정리만 하며, 최종 판단은 디자이너가 합니다. 개발 단계에서 저는 매장별 데이터를 나누는 멀티테넌시 구조와 서버를 맡습니다.

```plain text
예약 확정 → 디자이너가 링크 발송(10초) → 고객 사전 문진(3분) → 상담 카드 변환 → 디자이너 확인(30초)
```
