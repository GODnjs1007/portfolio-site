## 개요

내비게이션이 현재 위치에서 목적지까지 경로를 안내하듯, 목표 공고(목적지)와 현재 역량(현재 위치)의 차이를 진단하고 학교 안의 자원으로 학기별 경로를 안내합니다. 저는 진단 결과를 받아 보여주는 웹 서비스(서버·DB·화면)와 배포·운영을 맡고, 팀원이 AI 파이프라인을 맡습니다.

```plain text
내 경험 + 목표 공고 → 역량 갭 진단 → 교내 자원 추천 → 학기별 로드맵
```
