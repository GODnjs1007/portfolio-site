### E. 생성기 MQTT 송신

- 목적 : 기업 요청대로 TCP 말고 MQTT로도 보낼 수 있게 해서 비교 준비
    - 기업이 실제 제품에서 어느 방식을 사용할지 정하지 않아서 MQTT도 검토 중
    - 둘 다 만들어서 비교
- 설명 : --transport mqtt 옵션 추가. 환자별 토픽 ecg/{환자번호}로 보내고 받는 쪽은 ecg/+로 전부 구독. 서버에서 10명 × 10초 유실 0, 지연 p95 1.3ms
    - MQTT : 브로커가 중간에서 메시지를 받아 구독자에게 나눠주는 방식.
        - IoT 기기에서 많이 사용
    - 토픽 : MQTT 메시지에 붙이는 주소
        - 받는 쪽은 토픽을 구독해서 해당 메시지만 받는다
        - ecg/+ 의 +는 ecg/0 , ecg/1, ecg/2 …. 모든 환자 메시지를 한 번에 받음
    - 브로커 : 메시지를 받아서 나눠주는 중계 서버 (Mosquitto)
    - TCP와 차이 :
        - TCP : 생성기와 수신부가 직접 연결
        - MQTT : 브로커를 거침
            - 메시지 끝 줄바꿈 같은 경계 표시 필요 없음
