## 목표

미용실 사전 상담 아이디어로 2차 모두의 창업에 지원하고, 요건검토를 통과해 1라운드에 진출한다.

## A. 아이디어와 지원서

- 지원서 제출 (2026.09.17) — 트랙 일반/기술, 지역 강원, 멘토기관 연세대학교 미래캠퍼스 창업보육센터
- 문제 : 예약과 시술 사이에 아무 일도 일어나지 않는 공백이 있음
  - 고객은 자기 모발 상태(숱, 굵기, 손상도)와 원하는 스타일을 설명 못 함
  - 기장 추가금(2\~7만 원)을 방문 후에야 알게 됨 → 가격 불안, 노쇼
  - 디자이너는 시술 전 첫 10분을 매번 같은 질문으로 씀
- 해결 : 예약 후 3분짜리 사전 문진 → 디자이너가 30초에 읽는 상담 카드로 변환

```txt
예약 확정(네이버) → 디자이너가 링크 발송 → 고객 문진(3분) → AI가 상담 카드로 변환 → 디자이너 확인(30초)
```

- 차별점
  - 분기형 질문 : 네이버 추가 질문은 고정 10개. 답에 따라 다음 질문이 바뀜
  - 우회 질문 : 숱 → "고무줄 몇 바퀴?", 굵기 → "한 올 만지면 느껴지나?", 손상도 → "1년간 탈색·펌 몇 회?"
  - AI는 판정이 아니라 번역 : 진단 안 함, 최종 판단은 디자이너 → 진단 규제 회피
  - 기장 추가금 사전 안내 : 문진을 끝까지 쓸 동기 (응답률 문제 해결)
  - 예약 체계 안 바꿈 : 네이버 예약 뒤에 붙는 독립형
  - 멀티테넌시 : 서버 하나로 여러 매장을 따로 운영하는 구조
- 수익 모델 : 예약 20건 무료 → 1인샵 월 9,900 / 3\~5인 29,900 / 6인 이상 49,900, 셋업비 1회 5만 원
  - 재시술(5\~10만 원)이나 노쇼를 월 1건만 막아도 요금 회수
  - 확장 : 질문셋만 바꿔 출장 수리 · 청소 · 이사 견적
- 사업화 계획 (지원서 기준)
  1. 현장 검증 (1\~2개월) : 협력 미용실에서 구글폼 문진, 예약 20건
  2. MVP · 무료 파일럿 (2\~3개월) : 원주 3\~5곳, 응답률 40% · 열람률 50% · 완주율 70%
  3. 유료 전환 (3\~6개월) : 유료 매장 20\~30곳
  4. 확장 (6개월 이후) : 지역 · 업종 · 기능

## B. 요건검토와 1라운드 진출

- 요건검토 서류 8종 제출 (2026.09.30) — 신청구분 예비창업자
- 1라운드 진출 확정 — 2차 지원 92,838명 중 1라운드 10,000명 (경쟁률 9.3대 1)
- 플랫폼 프로필 등록 (2026.10.15) — 배너, 자기소개, 아이디어 요약
- 1라운드 지원 : 창업활동자금 200만 원, AI 솔루션 2개월 100만 원, 멘토링
  - 자산성 물품(노트북 등) 구입 불가, 서버 호스팅비는 가능
- 창업활동자금 카드 발급 확정 (2026.10.15) — 신한 선불카드, 국내전용(해외 결제 불가)
  - 사용 기간 : 수령 다음 날 \~ 2026.11.30, 남은 금액은 소멸
  - 쓴 내역이 2라운드 평가(활동자금 활용 적정성)에 반영됨
  - 미용실 업종은 결제 제한 업종
- 2라운드 평가 : 아이디어 차별성(서면) / 프로그램 참여 과정 · 활동 결과(관찰 + 서면)
  - 제출물 : 사업계획서 + 창업활동 · 멘토링 보고서
  - 사업자등록은 3라운드 진출 시 의무
