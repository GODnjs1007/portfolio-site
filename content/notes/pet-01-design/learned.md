### 연구 질문과 실험 설계

### A. AI가 하는 실수 두 종류

1. 놓침 : 사람이 사료 주라고 말은 했지만 양은 말하지 않음. AI는 그냥 넘어가서 시터는 몇 g인지 모름
2. 혼자 결정 : A는 6시 산책, B는 7시 산책이라 했지만 AI는 묻지않고 혼자 결정함

—> 돌봄에서는 둘 다 위험 —> 물어볼 때는 물어보는 AI가 목표

### B. 연구 질문

1. 답을 정해진 칸 (JSON)에 채우기만 해도 실수가 줄어듦?
2. 그 칸을 코드로 한 번 더 검사하면 더 잡을 수 있음? 대신 어떤 걸 손해보는가

### C. 비교한 세 방식

- A : 자유요약 → 빈 종이에 알아서 메모하기
- B : 양식 추출 → 칸이 정해진 양식지에 채우기 (JSON)
    - JSON : {”동물”  : “콩이” , “양”  : null} 처럼 이름표에 붙은 값을 넣는 형식
        - 비어있으면 null
- C : 양식 + 코드 검사 → 양식지를 체크리스트로 한 번 더 확인
    - AI를 안 부르고 코드로 검사하는 이유 : AI는 부를 때마다 돈과 시간이 들고 답도 매번 달라지기 때문에 일관성있는 코드사용

### D. 사례와 공정성

- 개발용 10개 / 평가용 20개 :  개발용 10개로 먼저 실험 후 규칙을 만들고 나서 평가용을 돌린다
    - 규칙을 만들 때 개발용으로 채점하면 답을 외우고 시험을 보는 셈이라 처음 보는 사례로 해야 판가름이 나온다.
    - 평가용 20개 —> 물어봐야 하는 사례 6개 + 안 물어봐도 되는 사례 14개를 섞음
        - 물어봐야되는 사례만 넣으면 무조건 다 물어보는 AI가 100점을 받기 때문에 안 물어도 되는 사례를 섞어야 걸러짐
- 실행 전에 고정값 : 결과를 보고 정답이나 규칙을 고치면 결과를 맘대로 바꾸는 것이기 때문에 고정
- 10회 반복 : AI는 같은 질문을 해도 답이 조금씩 다르기 때문에 우연인지 잘 대답한 건지 확인하기 위해

### E. 지표

- 탐지율 : 물어봐야 할 사례에서 실제로 물어본 비율 (높을 수록 좋음 —> 안 놓침)
- 과잉 질의율 : 안 물어도 되는 사례에서 물어본 비율 (낮을 수록 좋음)
- 탐지율과 과잉 질의율 같이 봐야한다.
    - 무조건 다 물어보면 탐지율도 과잉 질의율도 100%임.
