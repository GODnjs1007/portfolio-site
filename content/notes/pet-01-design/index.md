## 목표

AI가 돌봄 지시를 정리할 때 생기는 문제를 어떤 방식이 줄이는지 공정하게 비교할 수 있는 실험을 설계한다.

## A. 문제

- 보호자가 카톡처럼 여러 번 나눠서 지시를 보내면, 중간에 시간이 바뀌거나 가족끼리 말이 엇갈림
- 이걸 AI에게 "정리해줘"라고 맡기면 두 가지 실수가 생김
  - 물어봐야 할 것을 놓침 (예: 급여량이 빠졌는데 그냥 넘어감)
  - 혼자 결정해버림 (예: 엄마는 18시, 아빠는 19시라고 했는데 아무거나 고름)

## B. 연구 질문

1. 출력 양식만 정해줘도(JSON) 자유 요약보다 실수가 줄어드는가?
2. 그 양식 결과를 코드로 한 번 더 검사하면, AI가 놓친 질문을 더 잡는가? 대가(쓸데없는 질문·시간·비용)는 얼마인가?

## C. 비교한 세 방식

| 방식 | 처리 | 비유 |
| --- | --- | --- |
| A 자유 요약 | "알아서 정리해" → 글로 출력 | 빈 종이에 메모 |
| B 양식 추출 | 할 일·금지사항·발신자·변경·질의 칸에 맞춰 JSON으로 출력 | 칸이 정해진 양식지 |
| C 양식 + 코드 검사 | B 결과를 파이썬 규칙으로 한 번 더 검사. AI 추가 호출 없음 | 양식지 + 체크리스트 |

## D. 사례와 공정성

- 가상 사례 30개
  - 개발용 10개: 프롬프트와 규칙을 만드는 데만 사용
  - 평가용 20개: 결과 측정에만 사용 → 만들 때 본 사례로 점수를 매기지 않음
- 평가용 20개 = 질문이 필요한 사례 6개 + 필요 없는 사례 14개
  - 섞은 이유: "무조건 다 물어보는" 방식이 점수를 따지 못하게
- 사례·정답·프롬프트·규칙 코드를 **실행 전에 고정**하고, 결과를 본 뒤에는 고치지 않음
- AI는 같은 질문에도 답이 달라서 사례당 10회씩 실행

## E. 지표

| 지표 | 뜻 | 좋은 방향 |
| --- | --- | --- |
| 탐지율 | 물어봐야 할 사례에서 실제로 물어본 비율 | 높을수록 |
| 과잉 질의율 | 안 물어도 되는 사례에서 물어본 비율 | 낮을수록 |
| 응답시간·토큰·비용 | 방식별 부담 | 낮을수록 |

- 탐지율만 보면 "다 물어보기"가 100%가 되니까, 과잉 질의율을 같이 봐야 함
