## 목표

수집을 멈추고 데이터를 백업한 뒤, 1~2쪽 논문을 써서 추계학술대회에 투고한다. 실측 서버는 끄고 정리한다.

## A. 수집 종료와 백업 (10.26)

```bash
crontab -r     # paper VM의 10분마다 실행 예약 삭제
crontab -l     # "no crontab" 나오면 중지 확인
```

- 마지막 기록: 10.26 10:30
- logs 폴더(probe_날짜.jsonl, cron.log)를 scp로 맥 `~/paper2-data/`에 복사 → 구글 드라이브 `논문/논문2_.../paper2-data`에 백업 (sim.py 포함)
- VM 디스크에만 있던 데이터를 두 곳에 둔 것

## B. 논문 작성

- 학회 일반 양식(hwpx)에 작성: 국문·영문 제목, Abstract, 주제어, Ⅰ 서론 ~ Ⅳ 결론, 참고문헌 3개
- 데이터: 유효 1,528건 (402 구간 1,057건 제외, 5단계 D)
- 교수님 검토 → "적정하다, 단독으로 해도 된다" → **단독 저자**
- 고친 것
  - 402 제외 설명을 "API 결제 문제"로 짧게 줄임 (빠진 기간은 밝히되, 사정은 생략)
  - 같은 문장 구조 반복("기다릴지, 재시도할지, 전환할지")과 일반론 문장을 줄이고, 서론을 선행 실험(논문 4의 429) 경험으로 시작
  - 결론을 "바람직하다" 대신 구체적 결과(T=3.5초 전환이 유일한 조합)로
