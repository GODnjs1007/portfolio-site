### A. 아이디어와 신청서
- 목적
    - 커리어 내비 아이디어를 신청서 양식에 맞춰 정리 후 제출
- 설명
    - 문제 정의
        - 학생은 목표 공고의 요구 역량을 지원 직전에야 앎
            - 늦은 인지
            - 연결의 부재 : 교내 프로그램이 어떤 직무 역량으로 이어지는지 모름
            - 경험 해석의 어려움
            - 방향 없는 스펙 쌓기
                - 근거
                    - 기업의 96.2%가 직무 경험 / 역량을 봄 (고용노동부)
                    - 구직자는 자격증 위주로 준비 (사람인)
    - 기존 서비스와의 차이
        - 취업 플랫폼 AI : 이미 쌓은 경험을 다듬어 줌 (자소서 코칭)
        - 공공 고용서비스 : 직업훈련 / 자격증 추천 중심 —> 학교 자원이랑 연결이 힘듦
        - 대학 추천 시스템 : 수강 이력 기준이라 특정 공고와 연결 X
        - <mark>커리어 내비! : 목표 공고를 기준으로 부족한 역량을 찾고 학교 자원으로 졸업 전에 역량을 채우게 도와줌</mark>
    - 주요 기능
        1. 경험 카드화
            - 이력서 / 활동을 LLM이 STAR 카드로 정리
        2. 공고 역량 분석
            - 필수 / 우대 / 직무 역량으로 나눔
            - NCS : 국가직무능력표준
                - 직무별로 필요한 능력을 나라가 정리해둔 기준
        3. 역량 갭 진단
            - 임베딩 유사도로 경험과 역량을 매칭
                - 규칙으로 충족 / 부분충족 / 미충족 판정 —> 근거 문장 표시
                - 임베딩 : 문장을 숫자 목록으로 바꾼 것 / 뜻이 비슷하면 숫자도 가까움
        4. 교내 지원 추천
            - 교과목 / 비교과 / 현장실습 / 자격증을 RAG로 검색
                - RAG : 질문과 관련된 자료를 먼저 찾아서 AI 답변의 근거로 쓰는 방식
        5. What-If
            - 추천 항목을 이수하면 적합도가 얼마나 오르는지 계산
        6. 학기별 로드맵
            - 남은 학기에 맞춰 언제 무엇을 들을지 결정
    - 시스템 설계
        - 화면 : React (반응형 웹) / 서버 : Python FastAPI
            - 리엑트 : 화면(프론트) 만드는 자바스크립트 라이브러리
            - Fast API : 파이썬으로 만든 API 서버 만드는 프레임워크
        - LLM은 경험 카드화 / 역량 추출 , 결과는 JSON
            - 충족 여부와 적합도 점수는 규칙 기반 코드 (LLM X) → 환각 막고 기준 공개
                - 환각 (할루시네이션) : AI가 없는 사실을 그럴듯하게 지어냄
        - 교내 자원은 벡터 DB에 저장해서 검색
            - 벡터 DB : 임베딩 (숫자 목록)을 저장하고 비슷한 것끼리 빠르게 찾아주는 데이터베이스
    - 신뢰성 / 개인정보
        - 근거가 부족하면 판단보류로 표시 (억지로 판정 X)
        - 자소서 대필 기능 X
        - 업로드한 원본은 보관 X , 학교 통계는 익명으로
    - 검증 계획과 성과 지표
        - 검증 1 : 실제 공고 50건의 역량 추출 결과를 우리가 만든 정답지와 비교
        - 검증 2 : 재학생 사용성 테스트
        - 성과 지표 : 진단 후 비교과 / 현장실습 신청 전환율 / 로드맵 이행률 / 진단 전후 적합도 변화  만족도
        - 사용성 테스트 : 실제 사용자에게 써보게 하고 불편한 점 찾기
