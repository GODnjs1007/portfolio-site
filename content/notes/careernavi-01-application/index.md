## 목표

'커리어 내비' 아이디어로 2026학년도 캡스톤디자인 경진대회 신청서를 작성하고 제출한다.

## A. 아이디어와 신청서

- 신청서 양식 : 아이디어명 / 지도교수 / 참여학과 / 팀명 / 참여학생 / 과제 목적 / 과제 내용 / 활용방안 및 기대효과
  - 아이디어명 : 커리어 내비 : 목표 채용공고까지 부족한 역량을 찾아 학교 안에서 채워주는 AI 로드맵 서비스
  - 팀 갭스톤, 소프트웨어학부, 팀원 · 이해원, 지도교수 미정
- 문제 : 목표 공고의 요구 역량을 지원 직전에야 알게 됨
  - 늦은 인지 : 채울 시간이 없음
  - 연결의 부재 : 교내 프로그램이 어떤 직무 역량으로 이어지는지 모름
  - 경험 해석의 어려움 : 이미 가진 경험이 공고 요건에 해당하는지 판단 못 함
  - 방향 없는 스펙 쌓기 : 직무 경험 대신 자격증·어학부터
  - 근거 : 500대 기업 96.2%가 직무 경험·역량을 봄 (고용노동부, 2024) vs 구직자는 자격증 48.8%로 준비 (사람인, 2021)
- 기존 서비스 한계 : 취업 플랫폼 AI는 이미 쌓은 경험을 다듬기, 공공 서비스는 대학 자원과 미연결, 대학 추천은 특정 공고와 미연결
- 주요 기능
  1. 경험 카드화 : 이력서·성적표·활동을 LLM이 STAR(상황·역할·행동·성과) 카드로 정리
  2. 공고 역량 분석 : 필수·우대·직무 역량으로 분류, NCS에 매핑
  3. 역량 갭 진단 : 임베딩 유사도로 매칭 → 규칙 기반으로 충족·부분 충족·미충족 판정, 근거 문장 표시
  4. 교내 자원 추천 : 교과목·비교과·현장실습·자격증을 RAG로 검색
  5. What-If : 이수했을 때 적합도 변화와 지원 가능 공고 수
  6. 학기별 로드맵 : 남은 학기·개설 학기·선수과목·졸업요건 반영
- 시스템 설계
  - 화면 React(반응형 웹) / 서버 Python(FastAPI)
  - LLM은 경험 카드화·역량 추출만, 결과는 JSON 형식
  - 충족 여부·적합도는 LLM이 아닌 규칙 기반 코드로 계산 → 환각 방지, 기준 공개
  - 교내 자원 DB : 편람·강의계획서·비교과 공지를 벡터 DB에 저장 (RAG)
  - 데이터 : NCS, 고용24 채용정보, 교과목 편람, 비교과 공지
- 신뢰성·개인정보 : 근거 부족 시 '판단 보류', 자소서 대필 기능 없음, 원본 파일 분석 후 미보관, 학교 통계는 익명
- 검증 계획 : 실제 공고 50건 역량 추출을 사람 분류와 비교, 재학생 사용성 테스트
- 성과 지표 : 진단 후 비교과·현장실습 신청 전환율, 로드맵 이행률, 진단 전후 적합도 변화, 만족도
