## 프로젝트별 메모

### 1. AWS 인프라 10단계
단계 이름(노션 기록 기준): 1 EC2 + Nginx 기본 배포 / 2 커스텀 웹페이지 배포 / 3 장애 발생 및 트러블슈팅 / 4 VPC·보안 설정 / 5 ALB·Auto Scaling / 6 Terraform 자동화 / 7 Terraform 기반 Private RDS / 8 Docker·ECS / 9 CloudWatch 모니터링 / 10 비용·보안 최적화.
- 할 일: 단계별 요약·구조도·트러블슈팅을 노션에서 옮기기. 비용 수치는 실제 기록이 있을 때만.

### 2. Proxmox 홈랩
- 구성: 미니PC 1대(pve, i5-14450HX / RAM 16GB / NVMe 512GB) 위 VM 2개. `portfolio`(VM 100, 4코어 / 4GB / 38GB), `ecg`(VM 101, 4코어 / 6GB / 39GB).
- 접속: Tailscale 사설망, SSH 키 인증, 비밀번호 로그인 차단. 공유기 포트 개방 없음.
- 단계: 1 Proxmox 설치와 원격 접속(완료) / 2 VM 원격 접속과 Docker(완료) / 3 포트폴리오 사이트 배포(진행 중) / 4 도메인·HTTPS 외부 공개 / 5 k3s 이전 / 6 GitHub Actions·Argo CD 자동 배포 / 7 모니터링.
- 할 일: 서버별 배운 점 작성(사용자), 도메인 결정, BIOS 정전 후 자동 부팅 설정.

### 3. 이 포트폴리오 사이트
- 할 일: 사이트 구조 개편 적용 후 제작·운영 기록 작성. 홈랩 페이지와 같은 내용을 반복하지 않는다.

### 4. 산학 ECG 서버
- 공개 가능한 것: 서버·백엔드 역할, 사용한 공개 데이터셋 종류, 일반적인 구조.
- 공개하지 않는 것: 기업명, 비공개 코드·데이터·설계, 연구 결과.
- 할 일: 기업에 공개 범위 확인.

### 5~9
- 결과가 확인되면 상태를 갱신하고, 공개할 자료가 생기면 초안을 채운다.
