# 노션 → Hugo 기록 글 변환 규칙

노션 단계 페이지 1개(와 그 하위 페이지 전부) = Hugo 기록 글 1개.

## 저장 위치
`content/notes/<slug>/index.md` (slug는 지정받은 값 그대로)

## 읽는 방법
- `mcp__Notion__notion-fetch`로 단계 페이지를 열고, 본문에 `<page url=...>`로 나오는 하위 페이지를 모두 재귀적으로 연다(하위의 하위까지).
- 페이지가 잘렸다(`truncated`)고 나오면 하위 블록을 추가로 열어 빠짐없이 읽는다.

## front matter
```yaml
---
title: "<프로젝트 접두어> <N>단계 · <노션 단계 제목에서 번호 뺀 것>"   # 예: "AWS 3단계 · 장애 발생 및 트러블슈팅"
date: YYYY-MM-DD        # 본문에 적힌 가장 이른 작업 날짜. 없으면 노션 페이지 생성일/수정일 중 이른 것
projects: ["<project slug>"]
step: <N>
summary: "<한 문장. 노션 본문의 목표/개요 문장을 그대로 또는 최소한으로 줄여서>"
tags: ["<태그>"]        # 아래 목록에서만: 구축, 트러블슈팅, 네트워크, 보안, IaC, 컨테이너, 모니터링, 비용, 데이터베이스, 리눅스
troubleshooting:        # 본문에 트러블슈팅 사례가 있으면 각 사례 제목. 없으면 빈 배열 []
  - "<사례 제목>"
draft: false
---
```

## 본문 변환
- **사용자가 쓴 문장을 그대로 옮긴다.** 요약·각색·새 문장 추가 금지. 순서도 노션 그대로.
- 하위 페이지는 `## <하위 페이지 제목>` 섹션으로 이어 붙인다. 하위의 하위는 `###`.
- 표 → Markdown 표. 셀 안 줄바꿈은 `<br>`.
- 코드 블록은 언어 표시 유지.
- 토글 → `<details><summary>제목</summary>\n\n내용\n\n</details>` (빈 줄 필수).
- 콜아웃 → `> ` 인용.
- 체크리스트 `- [x]` 그대로.
- 이미지: 다운로드 불가. 이미지 자리에 `<!-- 이미지: <캡션이나 앞뒤 문맥으로 본 설명> -->` 주석만 남긴다.
- 노션 내부 링크(다른 노션 페이지)는 링크를 빼고 텍스트만 남긴다. 외부 공개 URL(AWS 문서 등)은 유지.
- 이모지 장식은 제거.

## 반드시 지울 것 (민감정보)
- IP 주소: `100.x.x.x`(Tailscale), `192.168.x.x`, `10.x`/`172.16-31.x` 사설 IP, 퍼블릭 IP → `<Tailscale IP>`, `<내부 IP>`, `<퍼블릭 IP>` 처럼 자리표시로 바꾼다. 단 CIDR 설계 예시(`10.0.0.0/16`, `10.0.1.0/24` 같은 VPC 서브넷 설계)는 설명 내용이므로 그대로 둔다.
- AWS 계정 ID(12자리 숫자), Access Key(AKIA…), Secret, 토큰, 비밀번호, DB 비밀번호, ARN 안의 계정 ID → `<계정 ID>` 등으로.
- 이메일, 전화번호, 실명 외의 팀원 이름/계정명 → `팀원`. (사용자 본인 리눅스 계정명은 `<사용자>`로)
- 도메인/엔드포인트 중 실제 리소스 주소(xxx.elb.amazonaws.com, rds 엔드포인트, EC2 퍼블릭 DNS) → `<ALB DNS>` 등.
- 산학 ECG 관련: 기업명, 기업 제공 데이터·코드·설계·결과는 지운다. "산학 프로젝트 서버(VM 101)"라는 역할 설명과 일반 서버 설정(계정 분리, 키 인증, Docker 권한 등)만 남긴다. 팀원 키 공개키 문자열도 지운다.
- SSH 공개키/지문 문자열, Tailscale 공유 링크, GitHub 토큰 → 삭제.

## 끝나고 돌려줄 것 (짧게)
