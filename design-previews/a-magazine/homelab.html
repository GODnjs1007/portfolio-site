사용 기술
Proxmox VE, Ubuntu Server, Docker, Nginx, Tailscale, Hugo

개요

방에 둔 미니PC에 Proxmox를 설치해 VM 두 대로 나눴습니다. 하나는 이 사이트를, 하나는 산학 프로젝트 서버를 맡습니다. 집 밖에서는 공유기 포트를 열지 않고 Tailscale 사설망과 SSH 키로만 접속합니다.

시스템 구조

진행 단계

  1. Proxmox 설치와 원격 접속완료
  2. VM 원격 접속과 Docker완료
  3. 포트폴리오 사이트 배포진행 중
  4. 도메인·HTTPS 외부 공개예정
  5. k3s 이전예정
  6. GitHub Actions·Argo CD 자동 배포예정
  7. 모니터링예정

다음 작업

도메인을 정하고 HTTPS로 외부에 공개합니다. 그 전에 정전 후 자동 부팅을 BIOS에서 켜둘 계획입니다.

이 사이트는 Hugo로 만들어, 제 방 미니PC의 Proxmox VM에서 운영합니다.
