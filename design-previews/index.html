포트폴리오 디자인 시안 3개

내용은 같고 구조만 다릅니다. 각 시안마다 홈과 대표 프로젝트(Proxmox 홈랩) 상세를 만들었습니다. 실제 사이트에는 포함되지 않는 미리보기 전용 페이지입니다.

A 기술 매거진

큰 제목으로 읽히는 잡지 지면

  • 홈: 표지 문장 → 커버 스토리 1개 + 옆 기사 2개
  • 상세: 왼쪽 고정 요약, 오른쪽 긴 본문
  • 장점: 첫인상이 강하고 글이 잘 읽힘
  • 약점: 프로젝트가 늘면 지면 배치를 계속 손봐야 함

홈홈랩 상세

B 시스템 지도

추천 · 프로젝트끼리의 연결을 지도로

  • 홈: 분류별 지도(홈랩 안에 VM 두 대) + 같은 내용의 표
  • 상세: 접속 경로 도면 + 진행 단계 사이드
  • 장점: "AWS → 홈랩 → 그 위의 서비스" 흐름이 한눈에 보임. 인프라 직무와 가장 잘 맞음
  • 약점: 지도는 프로젝트가 많아지면 정리 규칙이 필요

홈홈랩 상세

C 엔지니어 작업실

시간순 작업 일지

  • 홈: 왼쪽 고정 소개·분류, 오른쪽 월별 일지(프로젝트와 기록이 섞임)
  • 상세: 노트 한 장, 서버 행을 펼치는 표
  • 장점: 꾸준히 쓰는 사람으로 보임. 글이 쌓일수록 좋아짐
  • 약점: 대표작이 시간에 묻힐 수 있음
